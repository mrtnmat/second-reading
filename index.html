Second Reading

Old games, read a second time: through their code.

draft

This site explains what we learn by taking old games apart: how they really work underneath, written so that you don't need to read code to follow it. Most of it is about King's Field, one of the first PlayStation games, and, over time, technical pieces that many games share.

It isn't a diary. Articles are revised as the research moves on, and the Recently updated page shows what changed.

How to read an article. Each one comes in three layers. In short is a few plain sentences. How it works explains the idea with examples. The details is for the technically curious: formulas, memory addresses, and how each claim was checked. Stop wherever you like. Underlined words are explained in the glossary.

How sure are we? Claims carry a label: measured means predicted from the program and then confirmed in the running game; in the code means read from the program but not yet tested; our reading is our interpretation. How we know what we know explains this further.
