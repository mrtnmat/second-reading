King's Field in numbers

draft

Plain tables for looking things up, with no story. The articles in King's Field, read from the code explain what the numbers mean; these pages just list them.

Every table carries one label for the whole table. Where only part of a table has been checked in the running game, the note under it says which part.

  1. 1Levels · draft

    Every level from 1 to 48: the EXP it takes, maximum HP and MP, and the STR and MAG each level adds.

  2. 2Monsters · draft

    Every monster on every floor: HP, EXP, gold, attack and defence, the status effects they cause and the items they drop, with the real chances.
